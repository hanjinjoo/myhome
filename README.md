# myhome
## 우리집 마당
가족의 일상과 사진, 익명 이야기를 나누는 게시판입니다.

사이트: https://hanjinjoo.github.io/myhome/

### 기능
- 로그인 없이 일상 및 사진 게시
- 익명 게시글과 익명 댓글
- 공감 버튼과 게시글 검색
- 모바일 화면 지원
- Cloudflare D1에 게시글과 댓글 저장, R2에 사진 저장

### 실행
Node.js 22.13 이상에서 아래 명령을 실행합니다.

    npm run install:ci
    npm run dev

데이터베이스가 필요한 기능은 D1 로컬 마이그레이션 적용이 필요합니다.
배포된 서비스의 데이터와 사진은 이 저장소에 포함하지 않습니다.
GitHub Pages에서 화면을 제공하고 별도 서버의 API로 글·사진·일정을 저장합니다.

### 가족 달력
- 월별 달력과 목록 보기, 날짜별 상세 일정
- 가족 모임·생일·기념일·여행 분류와 검색
- 하루 종일, 시작·종료 시간, 여러 날 일정
- 매년 반복되는 생일·기념일, 다음 생일까지 D-day
- 장소 지도 검색과 .ics 캘린더 파일 내려받기
- 작성한 브라우저에서 일정 수정·삭제
- 실제 가족 생일 데이터는 서비스 저장소에만 보관하며 소스에 포함하지 않습니다.


### GitHub Pages 화면 만들기
화면과 저장 서버를 각각 배포합니다. 화면은 아래 명령으로 생성됩니다.

    node scripts/build-pages.mjs

생성된 pages-dist/의 파일을 GitHub Pages 게시 위치에 올립니다.
저장 서버는 기존 Sites 배포를 사용하며 허용된 GitHub 출처의 요청만 연결합니다.
원래 주소에서 만든 일정의 편집 권한은 기존 서버의 /api/transfer 링크를 한 번 열어 가져올 수 있습니다.
