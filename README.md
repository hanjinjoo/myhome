# myhome
## 우리집 마당
가족의 일상과 사진, 익명 이야기를 나누는 게시판입니다.

사이트: https://our-family-garden-1028.ycqg-40.chatgpt.site

### 기능
- 로그인 없이 일상 및 사진 게시
- 익명 게시글과 익명 댓글
- 공감 버튼과 게시글 검색
- 모바일 화면 지원
- Cloudflare D1에 게시글과 댓글 저장, R2에 사진 저장

### 실행
Node.js 22.13 이상에서 아래 명령을 실행합니다.

    npm run install:ci
    npm run dev

데이터베이스가 필요한 기능은 D1 로컬 마이그레이션 적용이 필요합니다.
배포된 서비스의 데이터와 사진은 이 저장소에 포함하지 않습니다.
이 프로젝트는 서버와 저장소를 사용하므로 GitHub Pages만으로 전체 기능을 실행할 수 없습니다.
